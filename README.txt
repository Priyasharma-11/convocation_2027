ADYPU Convocation 2027 - Save the Date (Class of 2027)
=====================================================

OPEN IT
  Double-click index.html. It opens in any modern browser (Chrome, Edge, Safari, Firefox).
  An internet connection is needed for the fonts (Google Fonts). Without one, the page
  still works but shows fallback fonts.

HOST IT
  index.html is fully self-contained (the crest is embedded inside it). Upload just that
  one file to any web host or the university website and it will work as is.

EDIT THE DETAILS
  Open index.html in a text editor and search for "const EVENT". Change:
    dateText  e.g. "Saturday, 16 January 2027"
    ddMonth   e.g. "16 January"
    venue     e.g. "Main Lawn"   (shown in the details panel)
    dateISO   e.g. "2027-01-16"  (used by Add to calendar)
    startISO  add a time later, e.g. "2027-01-16T18:00" (IST)
  These update the card, top bar and details panel together.

ADD TO CALENDAR
  Outside Claude, the button opens a Google Calendar link for the event.
